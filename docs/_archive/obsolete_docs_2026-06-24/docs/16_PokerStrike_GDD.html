개요 & 기술 스택

포커 패 기반 유닛 소환 + 타워 디펜스 하이브리드 게임. 카드 조합으로 유닛을 소환하고 그리드에 배치하여 본진을 방어한다. 로그라이트 요소(웨이브 클리어 시 패 강화 선택지)와 스테이지 진행 구조를 갖춘다.

덱 구성

카드 구성

  • 숫자: A K Q J 10 9 8 7 (8종)
  • 무늬: 4종 × 8 = 총 32장
  • 덱 소진 시 무덤 셔플 후 재드로우

무늬 = 속성

  • ♥ H 불 (Fire)
  • ♦ D 물 (Water)
  • ♣ C 땅 (Earth)
  • ♠ S 바람 (Wind)

핸드 & 공용 패

핸드 패 (5장 슬롯)

소환 또는 마법 사용 시 핸드 전체 소모 → 소액 비용으로 5장 새로 드로우. 패 교체는 1장씩 가능.

공용 패 (2장 슬롯) — 핸드와 완전 별개

게임 시작 시 덱에서 2장 자동 드로우, 항상 공개.
마법 스킬 발동 시에만 사용: 핸드 3장 + 공용 패 2장 = 5장으로 스킬 결정.
마법 사용 후 공용 패 2장 소모 → 덱에서 2장 자동 재드로우. 별도 교체 불가.

유닛 합성 시스템 구현 완료

같은 패 + 같은 등급 유닛이 2마리 배치되면 글로우 이펙트 발생. 한 유닛을 드래그해 같은 유닛에 겹치면 해당 위치에서 합성 → 다음 등급 유닛 생성.
같은 패+등급 2마리 → 글로우
→
드래그로 겹치기
→
합성 (드래그 대상 위치)
→
다음 등급 유닛 생성

합성 규칙

  • 최대 3단계: 1등급 → 2등급 → 3등급
  • 속성(무늬)이 달라도 합성 가능
  • 합성 위치: 드래그 대상 유닛의 그리드 칸

등급 배율 (스탯)

  • 1등급: ×1.0 (기본)
  • 2등급: ×1.8
  • 3등급: ×3.2

그리드 & 적 AI 구현 완료

그리드 규격

  • 크기: 10 × 14 (cols × rows)
  • 셀 크기: 44 × 44px
  • 화면 오프셋: 좌 8px, 상 20px

적 AI

  • 경로 있음: A* 알고리즘 (Manhattan, 4방향)
  • 경로 없음: 가장 가까운 유닛/장애물 공격 후 돌파
  • 유닛 배치/제거 시 전체 경로 재계산

전투 시스템

유닛/적 모두 자동 공격. 사거리 내 적 탐지 → 공격 쿨다운마다 자동 타격. 속도 버프 유닛은 주변 아군에 공격속도 버프 지속 적용.

  • 일반 스테이지: 20~30분

## 개요

PokerStrike는 포커 족보로 유닛 소환과 마법을 결정하는 세로형 카드 디펜스 게임이다. 플레이어는 손패 5장과 공용패 2장을 읽고, 소환/교체/마법 중 하나를 선택해 웨이브를 방어한다.

## 현재 UI 변경 사항

- 카드패 탭의 손패 위 보조 라벨을 제거했다.
- 공용패 라벨 옆에 `무덤 N` 카운트를 표시한다.
- 마법 사용 시 손패와 공용패에서 소모된 카드는 일반 버림패와 분리된 마법 무덤에 누적된다.
- `카드패`, `업그레이드`, `강화 목록` 탭을 더 넓은 탭 바 형태로 표시해 현재 선택된 패널을 명확히 구분한다.
- 업그레이드 탭의 강화 버튼은 박스형 버튼으로 정리하고 hover 상태를 제공한다.
- 첫 스테이지 클리어 직후 업그레이드 튜토리얼을 1회 표시한다.
- 예시 이미지의 HUD형 구성을 참고해 상단 자원 표시를 박스형으로 정리했다.
- 골드와 보석은 하나의 자원 클러스터 안에 모아 표시한다.
- 체력은 상단 HUD에서 제거하고 본진 칸의 HP 바로만 표시한다.
- 웨이브 UI는 자원 클러스터와 떨어진 별도 배지로 표시한다.
- 하단 패널은 탭 바, 카드, 미리보기/액션 버튼이 서로 겹치지 않도록 고정 구획으로 재배치했다.
- 공용패/무덤 라벨과 족보 미리보기는 카드 위에 겹쳐 띄우지 않고 전용 라벨 줄에 표시한다.
- `카드패`, `업그레이드`, `강화 목록` 탭은 카드 위쪽에 배치한다.
- 카드 UI는 속성색 테두리, 밝은 카드 면, 큰 숫자 중심으로 가독성을 높였다.
- 속성 표기는 한글 속성명 대신 `♥`, `♦`, `♣`, `♠` 카드 문양 아이콘만 사용한다.
- 카드 중앙 숫자와 하단 속성 아이콘을 더 크게 표시한다.
- 소환될 족보 미리보기는 더 큰 글꼴로 표시한다.
- 화면에 노출되는 깨진 한글 문자열을 정상 한국어로 정리했다.
- 전장 위에 직접 겹치던 상태 글자는 전장 하단 메시지 슬롯과 고정 정보 패널에 표시한다.
- 적 정보 패널은 적을 따라다니지 않고 우측 상단 고정 구역에 표시한다.
- 그리드 셀 크기를 소폭 줄여 전장과 하단 UI 사이에 텍스트 전용 안전 구역을 확보한다.
- 적 유닛은 단색 도형 대신 타입별 색상과 장식이 있는 몬스터 그래픽으로 표시한다.

## 카드 흐름

- 소환: 손패 5장을 버림패로 보내고 새 손패를 뽑는다.
- 교체: 선택한 손패 1장을 버림패로 보내고 새 카드 1장을 뽑는다.
- 마법: 손패 5장과 공용패 2장을 마법 무덤으로 보내고, 새 손패와 새 공용패를 뽑는다.

## 무덤 카운트

무덤 카운트는 마법으로 소모되어 이번 세션의 덱 순환에서 빠진 카드 수를 뜻한다. 일반 소환/교체로 버린 카드는 이 카운트에 포함하지 않는다.

## 웨이브 강화 선택지

- 현재 대상 유닛이 1명 이상인 유닛 강화만 선택지에 등장한다.
- 예를 들어 물 속성 유닛이 없으면 물 속성 공격력/감속/사거리 강화는 후보에서 제외된다.
- 드로우 비용 감소처럼 현재 유닛을 직접 대상으로 삼지 않는 경제형 강화는 계속 등장할 수 있다.
- 강화 선택지가 표시되는 동안 시간 경과 골드 수입은 일시 정지된다.
- 강화 선택지의 제목/효과 글꼴은 전투 중에도 읽기 쉽도록 크게 표시한다.

## 업그레이드 구조

- `◆` 보석 강화는 모든 타워에 적용되는 영구 HP/ATK 성장이다.
- 골드 문양 강화는 `♥`, `♦`, `♣`, `♠` 중 선택한 문양 타워의 공격력만 10% 올린다.
- 골드 문양 강화는 45G로 비용 대비 효율은 낮지만 원하는 문양을 보강하는 선택지다.
- 유닛을 직접 선택하면 기존처럼 개별 HP/ATK 강화도 사용할 수 있다.

## 전투 밸런스 변경

- 스트레이트 플러시 오라 유닛은 주변 아군 중 같은 속성 유닛만 공격 속도를 강화한다.
- 오라로 강화 중인 유닛 위에는 `강화` 상태 표시가 뜬다.
- 바람 속성 단일 공격은 더 이상 방어력을 관통하지 않고, 방어형 몬스터의 방어력에 따라 피해가 감소한다.
- 땅 속성 유닛은 공격 시 대상에게 방어력 감소 효과를 적용한다. 등급이 높을수록 방어력 감소량이 커진다.
- 모든 이동속도 감소 효과는 지속시간이 끝나면 적의 원래 이동속도로 복구된다.
- 적 유닛을 클릭하면 해당 적의 HP와 현재 방어력을 확인할 수 있다.
- 방어력 감소 상태는 수치 없이 `방어력 감소 중`으로만 표시한다.
- 경로가 완전히 막힌 적은 막힌 셀을 통과하지 않고, 막고 있는 타워 셀 밖에서 멈춰 공격한다.

## 스테이지 구성

- 모든 스테이지의 마지막 웨이브에는 보스 몬스터가 최소 1회 이상 등장한다.
- 실제 스폰되는 적 수량은 1스테이지 2배를 기준으로, 스테이지가 오를수록 지수 배율로 증가한다.
- 스테이지별 적 수량 배율은 `2 * 1.35^(스테이지-1)`을 반올림해 적용한다.
- 각 스테이지의 1웨이브는 스테이지 배율의 55%만 적용해 쉽게 시작하고, 마지막 웨이브는 160%까지 올려 후반 압박을 강화한다.
- 적 스폰 최소 간격은 120ms로 유지하고, 같은 웨이브의 적 그룹은 시작 시간을 조금씩 엇갈리게 해 한꺼번에 쏟아지는 느낌을 줄인다.

## 검증 항목

- 마법 1회 사용 후 무덤 카운트가 7 증가한다.
- 소환/교체는 무덤 카운트를 증가시키지 않는다.
- 공용패 영역에서 무덤 카운트를 항상 확인할 수 있다.
- 탭 전환 시 카드패/업그레이드/강화 목록의 선택 상태가 시각적으로 구분된다.
- 업그레이드 튜토리얼은 첫 스테이지 클리어 후 한 번만 표시된다.
- 업그레이드 버튼은 보석 전체 강화, 골드 문양 강화, 본진/개별 유닛 강화로 구분된다.
- 하단 카드, 미리보기 문구, 액션 버튼, 탭 바가 서로 겹치지 않는다.
- 카드와 강화 선택지의 속성 표기는 한글명 없이 카드 문양 아이콘만 표시한다.
- 족보, 공용패, 무덤 텍스트는 각각 확보된 라벨 영역 안에 표시된다.
- 강화 선택지 화면에서 골드가 계속 증가하지 않는다.
- 강화 선택지 제목과 적용 대상 텍스트는 큰 글꼴로 표시된다.
- 골드/보석 자원 표시와 웨이브 표시는 별도 패널로 구분된다.
- 화면 표시 문자열에 깨진 한글이 노출되지 않는다.
- 상태 메시지와 적 정보 글자는 전장/하단 UI와 겹치지 않는 고정 구역에 표시된다.
- 적 유닛은 기본 도형이 아니라 몬스터 그래픽으로 표시되고, 타입별 실루엣이 구분된다.
- 전투 메시지 슬롯은 하단 UI 영역을 침범하지 않는다.
- 웨이브 강화 선택지는 대상 유닛이 없는 유닛 강화를 표시하지 않는다.
- 오라 강화는 같은 속성 아군에게만 적용되고, 강화 상태 표시가 보인다.
- 단일 공격은 방어력에 영향을 받으며, 땅 속성 공격은 방어력 감소 상태를 적용한다.
- 물 속성 감속과 마법 감속은 지속시간 종료 후 원래 이동속도로 돌아온다.
- 적 클릭 정보 패널은 HP와 방어력을 표시하며, 방깎 수치를 별도로 노출하지 않는다.
- 경로 없음 상태의 적은 상하좌우 및 대각선 접근 모두에서 막힌 타워 셀 경계를 넘지 않는다.
- 각 스테이지 마지막 웨이브에는 보스 그룹이 포함된다.
- 웨이브 스폰 큐는 스테이지가 높을수록 지수적으로 더 많은 적을 생성한다.
- 같은 스테이지 안에서는 1웨이브가 가장 쉽고, 뒤쪽 웨이브일수록 더 많은 적을 생성한다.
- 밀집 웨이브에서도 연속 스폰 간격은 최소 120ms 이상으로 유지된다.

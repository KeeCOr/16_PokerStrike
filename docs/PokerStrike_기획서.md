# PokerStrike 기획서

## 핵심 개요
- PokerStrike는 포커 족보로 타워를 소환하고 웨이브를 막는 세로형 타워 디펜스 게임이다.
- 플레이어는 카드패를 보고 소환, 교체, 마법 중 하나를 선택한다.
- 높은 족보일수록 더 강한 타워와 마법 효과를 얻는다.

## 핵심 루프
- 카드 확인 -> 소환 또는 교체 -> 타워 배치와 합성 -> 웨이브 방어 -> 강화 선택 -> 다음 웨이브 준비.

## 현재 UI 기준
- 어두운 네이비 전장, 금속 골드 테두리, 시안과 골드 포인트를 기본 톤으로 사용한다.
- 버튼, 탭, 재화, 강화 선택지는 PNG UI 키트와 같은 블루와 골드 계열을 우선 사용한다.
- 메뉴, 게임오버, 강화 선택, HUD는 PokerStrike 이름과 동일한 UI 톤을 유지한다.

## 최근 적용 내용
- 메뉴 타이틀을 PokerStrike 브랜딩으로 정리했다.
- 하단 탭의 텍스트 아이콘을 제거해 탭 프레임 중심의 정돈된 UI로 맞췄다.
- 골드와 보석은 각각 분리된 프레임으로 표시하고 아이콘과 수량 간격을 좁혔다.
- 강화 선택 제목은 UI 키트 계열 프레임으로 통일하고 선택지 카드 크기와 래핑을 조정했다.
- 게임오버 화면은 결과 패널, 전투 결과 요약, 이미지 기반 재시작 버튼을 사용한다.
- 이동 중 사정거리는 낮은 알파의 바닥 데칼로 표시한다.
- 타워 크기와 장식을 줄여 타일 시야를 확보했다.
- 전투 중 대미지, 처치, 상태이상 결과는 보드 위 플로팅 텍스트로 즉시 전달한다.
- 카드 UI는 핸드, 구분선, 공용패 영역을 고정해 카드와 포커 결과 라벨이 겹치지 않게 유지한다.

## 전투 및 보드
- 이동 가능한 보드 타일은 저채도, 저명도 버전으로 표시한다.
- 랜덤 소환 후보 영역은 약한 외곽선만 사용한다.
- 투사체는 이동 방향에 맞춰 회전한다.
- 타격 이펙트는 타일을 덮지 않게 작은 범위로 표시한다.

## 리소스 원칙
- 신규 UI는 기존 PNG 리소스의 금속 골드, 네이비 패널, 시안 포인트와 맞춘다.
- 임시 텍스트 기호는 버튼이나 탭 앞 장식으로 사용하지 않는다.
- 문서와 화면 문자열은 UTF-8 한글이 깨지지 않도록 관리한다.

## 배포 규칙
- portable 실행파일은 `PokerStrike_v{version}_portable.exe` 형식으로 관리한다.
- 프로젝트 루트, `release/`, `G:\내 드라이브\실행파일\`에는 최신 버전 하나만 유지한다.

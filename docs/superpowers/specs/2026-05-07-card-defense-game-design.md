# Card Defense Game — Design Spec
Date: 2026-05-07 (Updated)

## Overview

포커 패 기반 유닛 소환 + 타워 디펜스 하이브리드 게임.
카드 조합으로 유닛을 소환하고 그리드에 배치하여 본진을 방어한다.
로그라이트 요소(웨이브 클리어 시 패 강화 선택지)와 스테이지 진행 구조를 갖춘다.

---

- **1차**: 웹 브라우저 (Phaser 3)

## 카드 시스템

### 덱 구성
- A K Q J 10 9 8 7 × 4가지 무늬 = 32장
- 무늬 = 유닛 속성: 불 / 물 / 땅 / 바람

### 핸드 패 (5장 슬롯)
- 소환 또는 마법 사용 시 핸드 전체 소모
- 소모 후 소액 비용으로 5장 새로 드로우
- 덱 소진 시 무덤 셔플 후 재드로우

### 공용 패 (2장 슬롯) — 핸드와 완전 별개
- 게임 시작 시 덱에서 2장 자동 드로우, 항상 공개
- 마법 스킬 발동 시에만 사용: 핸드 3장 + 공용 패 2장 = 5장 조합
- 마법 사용 후 공용 패 2장 소모 → 덱에서 2장 새로 드로우
- 공용 패 교체는 마법을 사용할 때만 자연스럽게 갱신됨 (별도 교체 불가)

### 패 교체
- 핸드에서 원하는 카드를 선택적으로 교체 가능
- 비용 구조: 초기 10골드, 교체할수록 +2골드씩 누적 증가
- 새 핸드 드로우 시 교체 비용 초기화

---

## 비용(골드) 시스템

### 수입
| 수입원 | 수치 |
|--------|------|
| 기본 수입 | 1골드/초 (웨이브 진행마다 +0.5골드/초 증가) |
| 적 처치 | 일반 1~3골드, 특수 5골드, 보스 20골드 |

### 지출
| 지출 항목 | 비용 |
|-----------|------|
| 5장 드로우 | 5골드 |
| 카드 교체 (1장) | 10골드 시작, 교체마다 +2골드 누적 |
| 유닛 업그레이드 | 20~40골드 |
| 속성 전체 업그레이드 | 50골드 |

## 유닛 소환

포커 패 조합 → 유닛 등급 결정, 무늬 → 속성 결정

| 패 | 유닛 등급 | 비고 |
|----|-----------|------|
| 탑(노페어) | 0등급 (최하급) | 1장으로 즉시 소환 |
| 원페어 | 1등급 (일반) | |
| 투페어 | 2등급 (강화) | |
| 트리플 | 3등급 (희귀) | |
| 스트레이트 | 4등급 (고급) | |
| 플러시 | 4등급 (고급) | |
| 풀하우스 | 5등급 (영웅) | |
| 포카인드 | 5등급 (영웅) | |
| 스트레이트 플러시 | 6등급 (전설) | |

- 탑(노페어): 핸드에서 카드 1장을 선택해 즉시 소환 (가장 저렴한 소환)
- 나머지 패: 해당 조합을 이루는 카드들을 핸드에서 선택 후 소환
- 같은 패라도 무늬(속성)에 따라 다른 유닛 소환

---

## 유닛 종류 & 역할

각 속성(불/물/땅/바람)별로 아래 역할군 유닛이 존재한다.

| 역할 | 특성 |
|------|------|
| 공격형 | 단일 대상 높은 공격력 |
| 범위형 | 주변 적에게 낮은 공격력 |
| 지원형 (속도 버프) | 주변 아군 공격속도 증가 |
| 지원형 (감속) | 공격한 적의 이동속도 감소 |
| 탱커형 | 높은 HP, 낮은 공격력, 적 어그로 유도 |
| 저격형 | 긴 사거리, 낮은 공격속도 |

등급이 높을수록 같은 역할군 내에서 스탯 및 효과 범위 증가.

---

## 유닛 합성 시스템

- 같은 패 + 같은 등급 유닛이 2마리가 되면 **글로우 이펙트** 발생
- 플레이어가 한 유닛을 **드래그하여 같은 유닛에 겹치면** 해당 위치에서 합성
- 합성 결과: 다음 등급 유닛이 드래그 대상 위치에 생성
- 최대 3등급 (1→2→3)
- 속성(무늬)이 달라도 합성 가능

---

## 유닛 업그레이드 시스템

- 비용을 소모하여 특정 유닛 또는 특정 속성 전체를 업그레이드
- 효과: 스탯 영구 증가 (HP, 공격력 등) + 특수 능력 해금 (범위 공격, 독 부여, 관통 등)
- 업그레이드는 해당 스테이지 판 내에서만 유효 (영구 누적 아님)

---

## 마법 스킬 시스템

- 핸드 3장 + 공용 패 2장 = 5장 조합으로 스킬 결정
- 마법 사용 후 핸드 3장 + 공용 패 2장 모두 무덤으로
- 공용 패는 마법 사용 후 자동으로 덱에서 2장 새로 드로우

| 5장 조합 | 스킬 효과 |
|----------|-----------|
| 스트레이트 플러시 | 화면 내 적 전체 즉사 |
| 포카인드 | 적 전체에 대량 대미지 |
| 풀하우스 | 본진 HP 30% 회복 |
| 플러시 | 해당 무늬(속성) 아군 유닛 전체 공격력 50% 증가 (30초) |
| 스트레이트 | 화면 내 적 전체 이동속도 50% 감소 (15초) |
| 트리플 | 무작위 위치에 고등급 유닛 1기 즉시 소환 |
| 투페어 | 골드 30 즉시 획득 |
| 원페어 | 다음 드로우 비용 무료 |
| 탑 | 공용 패 2장 즉시 재드로우 |

## 그리드 맵 & 적 AI

- 그리드 크기: 10×18 (세로형)
- 적 스폰: 상단, 본진: 하단

### 적 AI
1. 경로 있음 → A* 경로탐색으로 이동
2. 경로 없음 → 가장 가까운 유닛/장애물 공격 후 돌파

### 전투
- 유닛/적 자동 공격 (사거리 내 적 탐지)
- 각 유닛/적: HP, 공격력, 공격속도, 사거리, 이동속도 보유

---

## 적 종류

| 적 | 특성 |
|----|------|
| 기본 보병 | 표준 스탯 |
| 탱커 | HP 3배, 이동속도 절반 |
| 질주병 | HP 절반, 이동속도 2배 |
| 공중 유닛 | 지상 유닛 무시하고 직선 이동, 공중 공격 가능 유닛만 공격 |
| 마법 면역 | 마법 스킬 효과 무효 |
| 분열형 | 사망 시 소형 적 2마리로 분열 |
| 재생형 | 일정 시간마다 HP 소량 회복 |
| 빙결형 | 주변 아군 유닛을 일정 시간 얼려서 공격 불가 상태로 만듦 |
| 보스 | 고유 능력 보유, 높은 HP/공격력 |

## 스테이지 & 웨이브 구조

### 플레이타임
- 일반 스테이지: 20~30분
- 보스 스테이지: 약 40분

### 진행 구조
- 스테이지 클리어 → 다음 스테이지 해금
- 최초 스테이지 클리어 시 **유료 재화** 지급
- 일정 스테이지마다 보스 스테이지 등장

### 웨이브 클리어 로그라이트 선택지
- 웨이브 클리어마다 3가지 강화 선택지 중 1개 선택
- 예시 선택지:
  - "투페어 유닛 공격력 +25%"
  - "불 속성 유닛 사거리 +1칸"
  - "스트레이트 패 소환 시 골드 +5 획득"
  - "카드 교체 비용 20% 감소"
  - "탑 유닛 HP +50%"

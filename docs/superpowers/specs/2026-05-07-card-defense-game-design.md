# Card Defense Game — Design Spec
Date: 2026-05-07 (최종 업데이트: 2026-05-08)

## Overview

포커 패 기반 유닛 소환 + 타워 디펜스 하이브리드 게임.
카드 조합으로 유닛을 소환하고 그리드에 배치하여 본진을 방어한다.
로그라이트 요소(웨이브 클리어 시 패 강화 선택지)와 스테이지 진행 구조를 갖춘다.

---

## 플랫폼 & 기술 스택

- **런타임**: Electron (포터블 실행파일)
- **렌더링**: Phaser 3 Canvas
- **씬 구성**: GameScene (게임 로직) + UIScene (카드/버튼 UI) 병렬 실행

## 카드 시스템

### 덱 구성
- A K Q J 10 9 8 7 × 4가지 무늬 = **32장**
- 무늬 = 유닛 속성: ♥불(H) / ♦물(D) / ♣땅(C) / ♠바람(S)

### 핸드 패 (5장)
- 항상 5장 유지
- 소환 시 핸드 전체 소모 → 덱에서 5장 새로 드로우
- 마법 시 핸드 전체 소모 → 덱에서 5장 새로 드로우
- 덱 소진 시 무덤 셔플 후 재드로우

### 공용 패 (2장)
- 게임 시작 시 덱에서 2장 자동 드로우, 항상 공개
- **마법 스킬 전용**: 핸드 3장 + 공용 패 2장 = 5장 조합으로 스킬 결정
- 마법 사용 후 공용 패 2장 소모 → 덱에서 2장 새로 드로우
- HIGH_CARD 마법 스킬(공용 패 교체)로도 갱신 가능

### 패 교체
- **교체 버튼 클릭** → 교체할 카드 선택 (카드가 녹색으로 하이라이트) → 클릭 시 교체 실행
- 비용: 10골드 시작, 교체할수록 +2골드 누적
- 소환(핸드 전체 소모) 시 교체 비용 초기화

## 비용(골드) 시스템

### 시작 자원
- 초기 골드: **15골드**

### 수입
| 수입원 | 수치 |
|--------|------|
| 기본 수입 | 0.5골드/초 |
| 웨이브 클리어 시 | +0.25골드/초 누적 증가 |
| 적 처치 | 기본병 2G, 탱커 5G, 질주병 2G, 공중 3G, 마법면역 5G, 분열 4G, 재생 4G, 빙결 5G, 보스 20G |

### 지출
| 항목 | 비용 |
|------|------|
| 소환 (핸드 5장) | 5G 시작, 소환할수록 +2G 누적 |
| 카드 교체 (1장) | 10G 시작, 교체마다 +2G 누적 (소환 시 초기화) |
| 본진 HP 회복 | 30G (+20 HP, 최대 100) |
| 유닛 HP 업그레이드 | 25G (+50%, 1회) |
| 유닛 ATK 업그레이드 | 20G (+30%, 1회) |

## 유닛 시스템

### 소환
- 핸드 5장의 포커 조합 → **아키타입(역할)** 결정
- 지배 무늬 → **속성 + 전투 메카닉** 결정
- 소환된 유닛은 빈 그리드 셀 중 하단 우선 무작위 배치

### 아키타입 (패 조합 → 기본 스탯 성격)

| 패 조합 | 아키타입 | 특징 |
|---------|---------|------|
| HIGH_CARD | 잡병 | 평범한 만능형 |
| ONE_PAIR | 탑 | 사거리 길고 느린 공격 |
| TWO_PAIR | 전사 | 근접 강타형 |
| THREE_OF_A_KIND | 마법사 | 중거리 마법 공격 |
| STRAIGHT | 기사 | 균형잡힌 전투형 |
| FLUSH | 민첩형 | 빠른 공격속도 |
| FULL_HOUSE | 정예 | 높은 스탯의 강력한 유닛 |
| FOUR_OF_A_KIND | 저격수 | 초장거리 느린 강타 |
| STRAIGHT_FLUSH | 신화 | 모든 스탯 최상위 |

### 파워 배율 (조합이 높을수록 압도적으로 강함)

| 패 | 파워 배율 |
|----|---------|
| HIGH_CARD | ×0.45 |
| ONE_PAIR | ×0.75 |
| TWO_PAIR | ×1.0 |
| THREE_OF_A_KIND | ×1.5 |
| STRAIGHT | ×2.0 |
| FLUSH | ×2.6 |
| FULL_HOUSE | ×3.4 |
| FOUR_OF_A_KIND | ×4.5 |
| STRAIGHT_FLUSH | ×6.0 |

### 속성별 전투 메카닉 (등급에 따라 강화)

| 속성 | 역할 | 등급1 | 등급2 | 등급3 |
|------|------|-------|-------|-------|
| ♥불 | 범위 공격 | 25% 확률 스플래시 | 50% 확률 스플래시 | 80% 확률 스플래시 |
| ♦물 | 슬로우 지원 | 60% / 단일 / 30% 둔화 | 80% / 반경1셀 / 45% 둔화 | 100% / 반경1.8셀 / 60% 둔화 |
| ♣땅 | 스턴 | 40% / 단일 / 0.6초 스턴 | 60% / 반경1셀 / 1.2초 스턴 | 90% / 반경1.8셀 / 2.2초 스턴 |
| ♠바람 | 저격 | +최대HP 5% 대미지 | +최대HP 10% 대미지 | +최대HP 18% 대미지 |

- 속성별 공격력/체력 수치 차이 없음 — 파워 배율과 아키타입으로만 결정
- ♥불/♠바람은 공중 유닛 공격 가능

### 등급 시스템

| 등급 | 스탯 배율 | 획득 방법 |
|------|---------|---------|
| 1등급 | ×1.0 | 소환 |
| 2등급 | ×1.8 | 같은 조합 1등급 2마리 합성 |
| 3등급 | ×3.2 | 같은 조합 2등급 2마리 합성 |

### 합성 방법
- 같은 패 + 같은 등급 유닛 2마리 시 **글로우 이펙트** 발생
- 한 유닛을 **드래그하여 같은 유닛에 겹치거나** 클릭으로 선택 후 다른 유닛 클릭
- 합성 결과: 드래그 대상 위치에 다음 등급 유닛 생성

### 유닛 인게임 업그레이드 (업그레이드 탭)
- 유닛 클릭 선택 후 업그레이드 구매
- HP +50% (25G), ATK +30% (20G) — 각 1회
- 본진 HP +20 (30G)

## 마법 스킬 시스템

핸드 3장 + 공용 패 2장 조합 기준:

| 5장 조합 | 스킬명 | 효과 |
|----------|--------|------|
| STRAIGHT_FLUSH | 절멸 | 화면 내 모든 적 즉사 |
| FOUR_OF_A_KIND | 대폭발 | 모든 적에게 500 대미지 |
| FULL_HOUSE | 회복 | 본진 HP +30 |
| FLUSH | 속성 강화 | 해당 속성 유닛 공격력 ×1.5 (30초) |
| STRAIGHT | 대지진 | 모든 적 이동속도 50% 감소 (15초) |
| THREE_OF_A_KIND | 소환 지원 | 무작위 위치에 트리플 유닛 1기 소환 |
| TWO_PAIR | 골드 획득 | 골드 +30 |
| ONE_PAIR | 소환 비용 초기화 | 소환 비용을 초기값(5G)으로 복구 |
| HIGH_CARD | 공용 패 교체 | 공용 패 2장 즉시 재드로우 |

- 마법면역(magicImmune) 적에게는 즉사·대미지·슬로우 스킬 무효

## 적 종류

| 적 | HP | 공격력 | 속도 | 보상 | 특성 |
|----|----|--------|------|------|------|
| 기본병 | 100 | 10 | 60 | 2G | 표준 |
| 탱커 | 400 | 15 | 30 | 5G | 느리고 내구력 높음 |
| 질주병 | 50 | 8 | 120 | 2G | 매우 빠름 |
| 공중 | 80 | 12 | 80 | 3G | 지상 유닛 무시, 직선 이동 |
| 마법면역 | 120 | 12 | 60 | 5G | 마법 스킬 무효 |
| 분열형 | 150 | 10 | 50 | 4G | 사망 시 기본병 2마리로 분열 |
| 재생형 | 200 | 10 | 55 | 4G | HP 5/초 재생 |
| 빙결형 | 90 | 8 | 65 | 5G | 반경 2셀 유닛을 2초 빙결 |
| 보스 | 2000 | 30 | 40 | 20G | 높은 HP/공격력 |

### 적 AI
- A* 경로탐색으로 본진(row 8의 임의 열)까지 최단경로 이동
- 각 적이 독립적으로 경로 계산 (같은 방향으로 몰리지 않음)
- 유닛 배치로 경로 차단 시 가장 가까운 유닛을 목표로 공격
- 본진 row 도달 시 1.5초마다 본진에 지속 공격

## 스테이지 & 웨이브 구조

### 스테이지 구성 (현재 4스테이지)

| 스테이지 | 웨이브 수 | 특이 사항 |
|---------|---------|---------|
| 1 | 3 | 입문. 기본병+질주병 |
| 2 | 4 | 탱커·재생·빙결·보스 등장 |
| 3 | 4 | 마법면역·분열·공중 등장 |
| 4 | 5 | 복합 조합, 마지막에 보스 2마리 동시 |

### 웨이브 클리어 로그라이트 강화

웨이브 클리어마다 **3가지 선택지 중 1개** 선택 (대상 유닛 하이라이트 미리보기 제공):

| 선택지 | 효과 |
|--------|------|
| 탑 유닛 공격력 +35% | HIGH_CARD 유닛 전체 |
| 원페어 유닛 공격력 +30% | ONE_PAIR 유닛 전체 |
| 투페어 유닛 공격력 +30% | TWO_PAIR 유닛 전체 |
| 트리플 유닛 공격력 +25% | THREE_OF_A_KIND 유닛 전체 |
| 범위형 공격력 +30% | 불 속성(AREA role) 전체 |
| 저격형 공격력 +40% | 바람 속성(SNIPER role) 전체 |
| 탱커 HP +50% | 땅 속성(TANK role) 전체 |
| 저격형 HP +60% | 바람 속성(SNIPER role) 전체 |
| 불 속성 사거리 +1칸 | 불 속성 유닛 전체 |
| 바람 속성 사거리 +1칸 | 바람 속성 유닛 전체 |
| 물 속성 사거리 +0.5칸 | 물 속성 유닛 전체 |
| 감속형 감속량 +20% | 물 속성(SUPPORT_SLOW role) 전체 |
| 드로우 비용 -2G | 소환 기본 비용 감소 |
| 교체 기본 비용 -3G | 교체 기본 비용 감소 |
| 원페어 소환 시 +5G | ONE_PAIR 소환마다 골드 획득 |
| 스트레이트 소환 시 +8G | STRAIGHT 소환마다 골드 획득 |

## UI 레이아웃

### 상단 HUD
- Wave 표시: 화면 최상단 중앙
- HP / 골드: 우상단

### 하단 UI 패널 (y ≥ 744)
- **카드 패 탭** (좌측): 카드 패 표시, 소환·마법·교체 버튼
  - 핸드 5장 (좌측) / 공용 패 2장 (우측) — 구분선으로 분리
  - 소환 버튼: 현재 핸드 조합 미리보기 표시
  - 마법 버튼: 핸드3+공용2 조합 스킬 미리보기 표시
  - 교체 버튼: 클릭 후 카드 선택 방식
- **업그레이드 탭** (좌측): 본진 회복 / 선택된 유닛 업그레이드

🃏 게임 개요

포커 패 기반 유닛 소환 + 타워 디펜스 하이브리드 게임.
카드 조합으로 유닛을 소환하고 그리드에 배치하여 본진을 방어한다.
로그라이트 요소(웨이브 클리어 시 강화 선택지)와 4스테이지 진행 구조를 갖춘다.

Phaser 3 Canvas Electron 포터블 실행파일 GameScene + UIScene 병렬 JavaScript ES Module

🎴 카드 시스템

덱 구성 (32장)

A K Q J 10 9 8 7 × 4가지 무늬

♥ 불 ♦ 물 ♣ 땅 ♠ 바람

핸드 패 (5장)

항상 5장 유지. 소환/마법 사용 시 핸드 전체 소모 → 덱에서 5장 새로 드로우. 덱 소진 시 무덤 셔플.

공용 패 (2장)

게임 시작 시 덱에서 2장 자동 드로우, 항상 공개 표시.

마법 스킬 전용: 핸드 3장 + 공용 패 2장 = 5장 조합으로 스킬 결정.

마법 사용 후 공용 패 2장 소모 → 덱에서 2장 새로 드로우. HIGH_CARD 마법으로도 갱신 가능.

패 교체

교체 버튼 클릭 → 교체할 카드 선택 (녹색 하이라이트) → 클릭 시 교체 실행

비용: 10G 시작, 교체마다 +2G 누적. 소환 시 초기화.

적 AI

• A* 경로탐색으로 본진(row 8의 임의 열)까지 최단경로 이동

• 각 적이 독립적으로 경로 계산 — 같은 방향으로 몰리지 않음

• 유닛 배치로 경로 차단 시 가장 가까운 유닛을 목표로 직접 공격

• 본진 row 도달 시 1.5초마다 본진에 지속 공격

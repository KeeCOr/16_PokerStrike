PokerStrike 기획서

포커 족보로 유닛 소환과 마법을 결정하는 세로형 카드 디펜스 게임.

현재 UI 변경 사항

  • 카드패 탭의 손패 위 보조 라벨을 제거했다.
  • 공용패 라벨 옆에 무덤 N 카운트를 표시한다.
  • 마법 사용 시 손패와 공용패에서 소모된 카드는 일반 버림패와 분리된 마법 무덤에 누적된다.
  • 카드패, 업그레이드, 강화 목록 탭을 넓은 탭 바 형태로 표시한다.
  • 예시 이미지의 HUD형 구성을 참고해 상단 자원 표시를 박스형으로 정리했다.
  • 체력은 상단 HUD에서 제거하고 본진 칸의 HP 바로만 표시한다.
  • 웨이브 UI는 골드/보석 자원 UI와 분리해 중앙에 표시한다.
  • 하단 패널은 탭 바, 카드, 미리보기/액션 버튼이 서로 겹치지 않도록 고정 구획으로 재배치했다.
  • 카드패, 업그레이드, 강화 목록 탭은 카드 위쪽에 배치한다.
  • 카드 UI는 속성색 테두리, 밝은 카드 면, 큰 숫자 중심으로 가독성을 높였다.
  • 소환될 족보 미리보기는 더 큰 글꼴로 표시한다.
  • 화면에 노출되는 깨진 한글 문자열을 정상 한국어로 정리했다.

카드 흐름

  • 소환: 손패 5장을 버림패로 보내고 새 손패를 뽑는다.
  • 교체: 선택한 손패 1장을 버림패로 보내고 새 카드 1장을 뽑는다.
  • 마법: 손패 5장과 공용패 2장을 마법 무덤으로 보내고, 새 손패와 새 공용패를 뽑는다.

무덤 카운트

무덤 카운트는 마법으로 소모되어 이번 세션의 덱 순환에서 빠진 카드 수를 뜻한다. 일반 소환/교체로 버린 카드는 이 카운트에 포함하지 않는다.

웨이브 강화 선택지

  • 현재 대상 유닛이 1명 이상인 유닛 강화만 선택지에 등장한다.
  • 예를 들어 물 속성 유닛이 없으면 물 속성 공격력/감속/사거리 강화는 후보에서 제외된다.
  • 드로우 비용 감소처럼 현재 유닛을 직접 대상으로 삼지 않는 경제형 강화는 계속 등장할 수 있다.
  • 강화 선택지가 표시되는 동안 시간 경과 골드 수입은 일시 정지된다.

전투 밸런스 변경

  • 스트레이트 플러시 오라 유닛은 주변 아군 중 같은 속성 유닛만 공격 속도를 강화한다.
  • 오라로 강화 중인 유닛 위에는 강화 상태 표시가 뜬다.
  • 바람 속성 단일 공격은 더 이상 방어력을 관통하지 않고, 방어형 몬스터의 방어력에 따라 피해가 감소한다.
  • 땅 속성 유닛은 공격 시 대상에게 방어력 감소 효과를 적용한다. 등급이 높을수록 방어력 감소량이 커진다.
  • 적 유닛을 클릭하면 해당 적의 HP와 현재 방어력을 확인할 수 있다.
  • 방어력 감소 상태는 수치 없이 방어력 감소 중으로만 표시한다.

스테이지 구성

  • 모든 스테이지의 마지막 웨이브에는 보스 몬스터가 최소 1회 이상 등장한다.

검증 항목

  • 마법 1회 사용 후 무덤 카운트가 7 증가한다.
  • 소환/교체는 무덤 카운트를 증가시키지 않는다.
  • 공용패 영역에서 무덤 카운트를 항상 확인할 수 있다.
  • 탭 전환 시 카드패/업그레이드/강화 목록의 선택 상태가 시각적으로 구분된다.
  • 하단 카드, 미리보기 문구, 액션 버튼, 탭 바가 서로 겹치지 않는다.
  • 강화 선택지 화면에서 골드가 계속 증가하지 않는다.
  • 화면 표시 문자열에 깨진 한글이 노출되지 않는다.
  • 웨이브 강화 선택지는 대상 유닛이 없는 유닛 강화를 표시하지 않는다.
  • 오라 강화는 같은 속성 아군에게만 적용되고, 강화 상태 표시가 보인다.
  • 단일 공격은 방어력에 영향을 받으며, 땅 속성 공격은 방어력 감소 상태를 적용한다.
  • 적 클릭 정보 패널은 HP와 방어력을 표시하며, 방깎 수치를 별도로 노출하지 않는다.
  • 각 스테이지 마지막 웨이브에는 보스 그룹이 포함된다.

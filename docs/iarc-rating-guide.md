**Important note for IARC reviewers:** PokerStrike uses poker hand rankings (pairs, straights, flushes, etc.) as a scoring and unit-power mechanic. This is a design device, not gambling. ## Notes for Submission

- The game is a **singleplayer, offline** Windows title.
- The poker hand evaluation system is a gameplay mechanic, not a gambling feature. If the IARC questionnaire asks about gambling, answer **No** and use the clarifying note field if available to describe the mechanic.
- All content is self-contained; no online features, no user communication, no IAP.
- The IARC tool will auto-generate region ratings from questionnaire inputs. The above recommendations reflect expected outputs for a family-friendly card strategy game.
